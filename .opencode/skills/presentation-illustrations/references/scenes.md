# Сцены иллюстраций

Каждая сцена — YAML-файл с полем `type`. Общие поля:

```yaml
type: ...
size: [1600, 560]     # необязательно
background: paper     # paper | transparent
margin: 100           # необязательно
```

Цвета задаются ключами из `illustrations.yaml`: `blue`, `red`, `orange`,
`teal`, `purple`, `ink`, `muted`, `line`, `card`.

## logic — прямой и инверсный ключ

```yaml
type: logic
title: "Инверсия в схеме"      # необязательно
value: 1                       # значение A: 0 или 1
cases:
  - label: "Прямой ключ"
    inverted: false
  - label: "Инверсный ключ"
    inverted: true
caption: "При A = 1 ..."
```

Рисует две панели: батарея, ключ, лампа. Для инверсного ключа карточка
красная пунктирная, лампа гаснет при `A = 1`. Значение лампы вычисляется
автоматически: лампа горит, когда ключ замкнут.

## gates — логические элементы

```yaml
type: gates
title: "Три операции"
gates:
  - kind: not
    input: 1
    output: 0
  - kind: and
    inputs: [1, 1]
    output: 1
  - kind: or
    inputs: [0, 1]
    output: 1
caption: "НЕ, И, ИЛИ ..."
```

`kind`: `not`, `and`, `or`. Рисуются стандартные обозначения элементов,
входные и выходные значения, выражение `F = ¬A`, `F = A · B`, `F = A + B`.

## array — массив

```yaml
type: array
title: "До и после"
rows:
  - label: "До"
    values: [42, 17, 68, 33]
    highlight: [2]         # синие ячейки
    selected: [0, 1]       # красный пунктир вокруг пары
    pointers: {0: "i", 1: "j"}   # метки над ячейками
  - label: "После"
    values: [17, 33, 42, 68]
caption: "..."
```

- `highlight` — индексы с синей заливкой.
- `selected` — индексы, обведённые красным пунктиром (сравниваемая пара).
- `pointers` — словарь «индекс → подпись»; рисуется чип над ячейкой.
- `show_index: false` — скрыть номера под ячейками.
- Максимум ~10 ячеек в ряду, иначе текст станет мелким.

## radix — разряды числа

```yaml
type: radix
size: [1600, 560]
digits: ["1", "0", "1", "1"]
weights: ["2³", "2²", "2¹", "2^0"]
values: [8, 4, 2, 1]
highlight: [0, 2, 3]          # ненулевые разряды
sum: "1·8 + 0·4 + 1·2 + 1·1 = 11"
caption: "1011 (двоичная) = 11 (десятичная)"
```

Показывает цифры числа, веса разрядов и сумму. Подходит для объяснения
позиционных систем счисления и перевода в десятичную.

- `weights` — подписи над карточками (`2³`, `2²`, `2¹`, `2^0`).
- `values` — значения разрядов (8, 4, 2, 1).
- `sum` можно не указывать — посчитается автоматически.
- `highlight` — индексы ненулевых цифр.

## division — деление в столбик

```yaml
type: division
size: [1600, 700]
number: 13
base: 2
answer: "1101"
```

Рисует цепочку делений **в российской записи уголком**: делимое слева,
делитель справа за вертикальной чертой, частное под делителем, произведение
под делимым, остаток под чертой. Остатки собраны справа, стрелка показывает
«снизу вверх», ответ — в плашке. Японская/американская запись (делитель
слева в скобке, частное над делимым) не используется.

Если `steps` не заданы, шаги считаются автоматически. Для перевода в другую
систему меняйте `base`: 2, 8, 16.

Подробные шаблоны — в скилле `presentation-examples`.

## recursion — стек вызовов

```yaml
type: recursion
size: [1600, 700]
function: factorial
calls: [4, 3, 2, 1]
returns: [24, 6, 2, 1]
base_label: "n <= 1 → return 1"
```

Карточки вызовов идут сверху вниз, стрелки «вызов» — вниз, «возврат» — вверх.
База выделена бирюзовым. Подходит для объяснения стека, базового случая
и порядка возврата значений.

## flow — процесс

```yaml
type: flow
direction: horizontal      # horizontal | vertical
steps:
  - title: "Сравнить"
    text: "a[j] и a[j+1]"
    mono: true
  - title: "Поменять"
    text: "если порядок нарушен"
highlight: [2]             # красный пунктир на шаге
caption: "..."
```

3–5 шагов. Стрелки оранжевые, с терминальными точками. `mono: true` —
моноширинный текст для кода и формул.

## layers — слои

```yaml
type: layers
layers:
  - label: "Регистры"
    text: "≈ 1 нс"
  - label: "Кэш"
    text: "≈ 10 нс"
highlight: 1               # выделить слой
caption: "..."
```

Каждый слой — карточка с цветной полосой слева. Подходит для иерархии
памяти, уровней OSI, стека технологий.

## schema — узлы и связи

```yaml
type: schema
direction: horizontal      # horizontal | vertical
nodes:
  - id: client
    title: "Клиент"
    text: "браузер"
    tone: blue
  - id: server
    title: "Сервер"
    text: "приложение"
    tone: teal
links:
  - from: client
    to: server
    label: "HTTP"
highlight: [server]
caption: "..."
```

Узлы — карточки, связи — оранжевые стрелки с подписями. `id` уникален.
Для вертикальной схемы используйте `direction: vertical`.

## tree — дерево

```yaml
type: tree
root:
  value: "50"
  left:
    value: "30"
    left: {value: "20"}
    right: {value: "40"}
  right:
    value: "70"
    left: {value: "60"}
    right: {value: "80"}
highlight: ["30", "20"]    # синие узлы
caption: "..."
```

До 15 узлов. Узлы — круги, значения — моноширинным. Подходит для BST,
кучи, разбора выражений.

## dots — точки

```yaml
type: dots
size: [600, 600]
background: transparent
count: 55
color: teal
seed: 7
min_radius: 5
max_radius: 22
```

Декоративный кластер без пересечений. `seed` делает результат
воспроизводимым. Используйте как акцент, а не как смысловую картинку.

## frames — рамки-заглушки

```yaml
type: frames
size: [1600, 860]
aspect: [1, 1]            # пропорции рамки, по умолчанию квадрат
items:
  - title: "Интерактивное приложение"
    label: "QR — заглушка"
    text: "Викторина в браузере: один файл, офлайн"
    tone: teal
caption: "..."
```

Карточки с пунктирной рамкой под вставку настоящей картинки: QR-код,
скриншот. `aspect` задаёт пропорции рамки — `[16, 9]` для скриншотов.
Когда настоящий QR или скриншот готов, замените сцену макетом `image`.

## Частые ошибки

- Слишком много текста в карточке → он выходит за рамки. Сократите до
  одного предложения.
- Заголовок слайда и заголовок картинки дублируются. Уберите один.
- Массив из 15 элементов: подписи становятся нечитаемыми.
- Красный пунктир на всех элементах сразу: выделение перестаёт работать.
- Иллюстрация спорит с темой: поменяйте `colors` в `illustrations.yaml`,
  а не правьте PNG.
