# Иллюстрации

## Когда использовать

- Нужна схема: логический элемент, электрическая цепь, сеть, архитектура.
- Нужно показать процесс или сравнение «до/после».
- Нужны массивы, деревья, слои памяти, таблицы-схемы.
- Нужен декоративный акцент (точки) для обложки/раздела.

Не используй иллюстрацию, если хватает `bullets`, `table`, `cards`
или `steps`: нативные макеты редактируются и весят меньше.

## Как это устроено

1. Пишется YAML-описание сцены (рядом с картинкой, в `assets/` презентации).
2. `scripts/illustrations.py` рисует PNG в стиле из
   `templates/default/illustrations.yaml`.
3. В `deck.yaml` картинка подключается через макет `image`.

```bash
python3 scripts/illustrations.py decks/01-algebra-logiki-8-klass/assets/logic.yaml
python3 scripts/illustrations.py docs/illustrations/specs --out docs/illustrations
python3 scripts/illustrations.py --types
```

PNG обязателен: PPTX не встраивает SVG. Стиль меняется в одном файле
`templates/default/illustrations.yaml` — палитра, сетка, радиусы, тени.
После правки стиля пересоберите все спецификации.

## Сцены

| Тип | Для чего | Размер по умолчанию |
| --- | --- | --- |
| `logic` | прямой и инверсный ключ, цепь с лампой | 1600×560 |
| `gates` | элементы НЕ, И, ИЛИ со значениями | 1600×560 |
| `array` | массив до/после, выделение элементов | 1600×660 |
| `radix` | разряды числа: цифра, вес, сумма | 1600×560 |
| `division` | деление в столбик, остатки, ответ | 1600×700 |
| `recursion` | стек вызовов: вызовы и возвраты | 1600×700 |
| `flow` | процесс из 3–5 шагов со стрелками | 1600×620 |
| `layers` | иерархия: память, OSI, уровни | 1600×620 |
| `schema` | узлы и связи: клиент → сервер → БД | 1600×620 |
| `tree` | двоичное дерево, иерархия | 1600×620 |
| `dots` | декоративный кластер точек | 600×600 |

Подробные поля — `references/scenes.md`.

## Правила

- Одна иллюстрация — одна мысль. Не пихайте в неё весь параграф.
- Не дублируйте заголовок слайда внутри картинки: заголовок уже есть в макете.
- Текст на картинке — не меньше 20 px при ширине 1600 px (иначе не видно
  с последнего ряда). Значения в ячейках — 32–40 px.
- Подпись слайда объясняет вывод, а не пересказывает картинку:
  «При A = 1 инверсный ключ разомкнут», а не «Схема».
- Примеры на картинке — в российской школьной записи: уголок при делении,
  десятичная запятая, пробел между разрядами, российские имена и реалии.
  Таблица записи — в `presentation-examples`.
- Цвета осмысленные: синий — основное, красный пунктир — инверсия/выделение,
  оранжевый — связи и провода, бирюзовый — бренд.
- Для `image`-слайда с подписью используйте картинку 1600×560, без подписи —
  1600×620.
- Спецификацию (`*.yaml`) храните рядом с PNG: через месяц будет понятно,
  откуда взялась картинка.
- Не рисуйте поверх PNG в редакторе: правка потеряется при пересборке.

## Проверка

- Откройте PDF и посмотрите слайд с расстояния ~1 м: подписи читаются?
- Нет ли наложений текста на провода и рамки?
- Совпадают ли значения на картинке с таблицей/текстом слайда?
- Запись примеров российская: уголок, запятая, пробелы между разрядами?
- Не спорит ли палитра картинки с темой презентации?

## Если стиль нужно поменять

Правьте только `templates/default/illustrations.yaml`:

- `colors` — палитра (например, сделать акцент синим вместо бирюзового);
- `grid` — шаг и толщина клетки;
- `cards` — радиус, обводка, тень;
- `fonts` — семейства (файлы шрифтов ищутся автоматически).

Затем:

```bash
python3 scripts/illustrations.py docs/illustrations/specs --out docs/illustrations
python3 scripts/illustrations.py decks/<папка>/assets/*.yaml
python3 scripts/build.py decks/<папка>
```
