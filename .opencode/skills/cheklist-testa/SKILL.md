# Чек-лист проверки

Пройди по пунктам и проверь каждое требование по коду HTML-файла.

## Содержание

- [ ] Пул заданий содержит ВСЕ задания из исходного файла.
- [ ] При каждом запуске показываются случайные 5 заданий (или все, если их меньше 5).
- [ ] Сохранён оригинальный формат каждого задания.
- [ ] У каждого задания есть номер, тип, полный текст (с инструкцией), варианты ответа и поле для ввода.

## Интерактивность

- [ ] Ответы можно вводить/выбирать.
- [ ] Есть навигация между заданиями («Назад»/«Далее»).
- [ ] Виден прогресс («Задание X из 5»).

## Ключевое требование (самое важное)

- [ ] До нажатия «Сдать тест» не видны правильные ответы, баллы и отметки «верно/неверно».
- [ ] Правильные ответы и пояснения закодированы (base64) и не читаются в исходном коде.
- [ ] Кнопка «Сдать тест» активна только после ответа на все задания текущего запуска.
- [ ] Экран результатов содержит баллы, оценку и разбор по каждому заданию (ответ ученика, правильный ответ, пояснение).

## Дополнительно

- [ ] Таймер на 10 минут с автосдачей по истечении времени.
- [ ] Кнопка «Пройти заново» сбрасывает ответы, таймер и выбирает новый случайный набор заданий.
- [ ] Крупный читаемый шрифт и крупные кнопки.

## Формат результата

Верни список замечаний в порядке убывания важности с указанием места в файле (номер строки или фрагмент), либо ровно: «Замечаний нет».
