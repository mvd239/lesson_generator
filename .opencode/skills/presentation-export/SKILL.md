# Экспорт одного формата

## Когда использовать

- Нужен конкретный файл: показать, распечатать, отправить, сдать.
- Нужно пересобрать один формат после правки слайда.
- Нужно убедиться, что файл открывается там, куда его понесут.

Не используй этот скилл, когда нужна диагностика сборки целиком или новый
шаблон: это `presentation-build`.

## Главное правило

**Один запуск — один формат.** Формат указывается явно и ровно один:

```bash
python3 scripts/build.py decks/<папка> --formats pdf     # верно
python3 scripts/build.py decks/<папка> --formats pptx,pdf,html   # неверно
```

Почему так:

- собираются только нужные файлы, время и место не тратятся на лишнее;
- `meta.formats` может перечислять хоть три формата — явный `--formats`
  его перекрывает;
- при ошибке сразу понятно, какой рендерер виноват;
- проверить один файл реально, а три «на всякий случай» — нет.

Если в `meta.formats` записано несколько значений, вызов **без** `--formats`
соберёт их все. Для экспорта одного файла так делать нельзя.

Нужны два файла — два запуска:

```bash
python3 scripts/build.py decks/<папка> --formats pptx
python3 scripts/build.py decks/<папка> --formats pdf
```

## Как выбрать формат

| Задача | Формат | Почему |
| --- | --- | --- |
| Показать с ноутбука, дать править | `pptx` | нативные объекты, заметки, правка в офисе |
| Сдать, распечатать, зафиксировать вёрстку | `pdf` | одинаково выглядит везде, шрифты внутри |
| Отправить одним файлом, открыть в браузере | `html` | автономный файл, картинки внутри |
| Нужны и показ, и печать | `pptx` + `pdf` | два отдельных запуска |

Если формат не назван — `pdf`: это умолчание проекта. `pptx` собирается,
только если презентацию будут править, `html` — если нужен показ в браузере.

## Команда и результат

```bash
python3 scripts/build.py decks/01-algebra-logiki-8-klass --formats pdf
```

Вывод:

```
  ✓ PDF    295 КБ  .../dist/algebra-logiki-8-klass/algebra-logiki-8-klass.pdf
```

Файл кладётся в `dist/<slug>/<slug>.<формат>`. Другое место — `--out <папка>`.

## Проверка именно этого файла

### PPTX

```bash
file dist/<slug>/<slug>.pptx        # Microsoft PowerPoint 2007+
unzip -l dist/<slug>/<slug>.pptx | tail -3
```

- Открыть в целевом офисе: Р7-Офис, МойОфис, LibreOffice или PowerPoint.
- Заметки докладчика на месте (панель «Заметки»).
- Таблицы не разъехались, шрифты не подменены, логотип виден на тёмных слайдах.
- Нет предупреждений о замене шрифта.

### PDF

```bash
file dist/<slug>/<slug>.pdf         # PDF document, version 1.4, N pages
```

- `N pages` равно числу слайдов из вывода сборки (`Слайдов: N`).
- Пролистать все страницы: нет обрезанного текста, наложений, пустых половин.
- Кириллица читается, шрифты встроены (ReportLab встраивает их при сборке).
- Размер страницы 16:9 (`13.333 × 7.5` дюйма) — при печати не «поедет».

### HTML

```bash
grep -c "<!DOCTYPE html>" dist/<slug>/<slug>.html
grep -c 'src="http\|href="http' dist/<slug>/<slug>.html   # должно быть 0
```

- Открыть локально, без интернета: картинки встроены как `data:`-URI.
- Нет внешних CDN, шрифтов и скриптов — файл работает из письма и с флешки.
- Печать из браузера (Ctrl/Cmd+P) даёт 16:9 — стили печати уже настроены.

## Если формат не поддерживается

```
Ошибка в презентации: Формат «docx» не поддерживается.
Доступны: pptx, pdf, html.
```

Поддерживаются только `pptx`, `pdf`, `html`. Другого формата в проекте нет;
не «дописывай» его в `parse_formats` на ходу — сначала обсуди с автором
проекта, потом добавляй рендерер.

## Что проверить до и после

- [ ] Формат назван явно, в `--formats` ровно одно значение.
- [ ] Сборка прошла без `✗` и без предупреждений `!` по слайдам.
- [ ] `file` показывает ожидаемый тип и число страниц (для PDF).
- [ ] Файл открыт глазами — целиком, а не только первая страница.
- [ ] Для HTML — открыт без сети.
- [ ] Старый файл в `dist/` перезаписан (проверь дату изменения).

## Чего не делать

- Не править готовый PDF/PPTX руками — правки только в `deck.yaml`.
- Не прописывать в `meta.formats` три формата «на всякий случай».
- Не отдавать HTML, если в него попали внешние ссылки.
- Не собирать «всё сразу», чтобы потом выбрать: это скрывает ошибку формата.
- Не менять `SUPPORTED` в `scripts/build.py` ради одного файла.
