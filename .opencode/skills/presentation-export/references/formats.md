# Форматы: что получается и как принимать

Три рендерера, три разных файла. Общая геометрия одна (16:9, цвета и шрифты
из `templates/default/theme.yaml`), но проверять каждый файл нужно по-своему.

| Формат | Рендерер | Зависимости | Что внутри |
| --- | --- | --- | --- |
| `pptx` | `scripts/render_pptx.py` на базе `base.pptx` | python-pptx | фигуры, текст, таблицы, PNG/JPG, заметки |
| `pdf` | `scripts/render_pdf.py` | ReportLab | страницы 13.333 × 7.5 дюйма, встроенные TTF |
| `html` | `scripts/render_html.py` | нет | один файл, стили и картинки внутри |

## PPTX

**Когда отдавать:** презентацию будут показывать с ноутбука и/или править —
учитель, методист, коллега.

**Что проверять:**

1. Открыть в целевом офисе (минимум один из Р7-Офис / МойОфис / LibreOffice).
2. Нет диалога «шрифт не найден» и автозамены.
3. Таблицы совпадают с PDF по числу строк и ширине колонок.
4. Заметки докладчика на месте.
5. Логотип виден на титуле и финальном конспекте, не перекрывает заголовок.
6. Код в блоке `code` не выходит за поля (до 18 строк, до 60 знаков в строке).

**Ограничения, заложенные в рендерер:**

- только базовые объекты — фигуры, текст, таблицы, PNG/JPG;
- нет SVG, SmartArt, 3D, анимаций и переходов;
- шрифты `Arial` и `Courier New` (метрически совместимы с Liberation Sans/Mono);
- только сплошные заливки, без теней и градиентов.

Это не недоработка, а условие одинакового открытия в четырёх офисах. Если нужно
сложное оформление — делайте его в PDF, PPTX остаётся редактируемым.

## PDF

**Когда отдавать:** сдача, печать, публикация, «чтобы точно так и выглядело».

**Что проверять:**

1. `file` показывает `PDF document` и число страниц — оно равно числу слайдов.
2. Пролистать целиком: нет обрезанного текста и наложений.
3. Кириллица читается, а не «квадратиками»: значит, TTF нашёлся и встроился.
4. Размер страницы 16:9 — при печати на A4 поля будут сверху и снизу,
   это нормально; главное, чтобы ничего не обрезалось.
5. Тёмные титул и финальный конспект пропечатываются (белый текст на цвете).

**Шрифты.** ReportLab берёт первый найденный TTF из системного набора:
Arial → Arial Unicode → Liberation Sans → DejaVu Sans. На разных машинах
файл может отличаться шириной строк — поэтому PDF и собирают как «эталон».
Если шрифт не найден вообще, сборка скажет об этом; лечится установкой
Arial, Liberation или DejaVu (см. `presentation-build/references/troubleshooting.md`).

**Чего в PDF нет:** заметок докладчика, редактируемого текста, ссылок на слайды.

## HTML

**Когда отдавать:** отправить одним файлом, открыть на чужом компьютере,
показать в браузере, вставить в LMS или на сайт.

**Что проверять:**

1. Открыть локально **без интернета** — всё должно отрисоваться.
2. `grep 'src="http\|href="http'` по файлу даёт 0: внешних зависимостей нет.
3. Картинки и логотип встроены как `data:`-URI, а не ссылками на `assets/`.
4. Навигация: стрелки, пробел, `N` — панель заметок, `?` — подсказка.
5. Печать из браузера (Ctrl/Cmd+P) даёт по странице на слайд, 16:9.

**Ограничения:**

- файл тяжелее PPTX: PNG-иллюстрации упакованы в base64 (примерно +33 % к размеру);
- это показ, а не редактирование: правки — только в `deck.yaml` и пересборка;
- шрифты системные (`Arial`, `Courier New`), на чужой машине вид может
  отличаться от PDF — если важна точность, отдавайте PDF.

## Что между форматами может отличаться

| Что | PPTX | PDF | HTML |
| --- | --- | --- | --- |
| Перенос строк в длинном тезисе | по метрикам офиса | по встроенному шрифту | по шрифту браузера |
| Заметки | есть, панель «Заметки» | нет | есть, клавиша `N` |
| Точность вёрстки | зависит от офиса | эталон | зависит от браузера |
| Правка после сборки | да | нет | нет |
| Размер файла | средний | средний | крупный (base64) |
| Работа без сети | да | да | да |

Правило приёмки: один и тот же слайд может переноситься по-разному, но не должен
обрезаться ни в одном формате. Если обрезка есть только в PPTX — сокращайте
текст, а не подгоняйте шрифт.

## Быстрая приёмка одной командой

```bash
D=dist/<slug>/<slug>
file $D.pdf $D.pptx
grep -c 'src="http\|href="http' $D.html
du -h $D.pdf $D.pptx $D.html
```

Дальше — глазами: PDF целиком, PPTX в одном офисе, HTML без сети.
