# Типовые темы по информатике

Опорные понятия, каркас и типичные ошибки. Используй как отправную точку,
а не как готовый текст: подстраивай под класс и регламент.

## Алгоритмы и сложность

**Понятия:** алгоритм, исполнитель, свойства алгоритма, блок-схема, сортировка,
поиск, рекурсия, O-нотация, лучший/средний/худший случай.

**Каркас:** задача → алгоритм → пример по шагам → сложность → сравнение → вывод.

**Ошибки:** «алгоритм — это программа»; путать O(n²) и время в секундах;
считать, что быстрая сортировка всегда O(n log n).

## Алгебра логики (8 класс)

**Понятия:** высказывание, истина/ложь, 1/0, инверсия (НЕ), конъюнкция (И),
дизъюнкция (ИЛИ), таблица истинности, логический элемент, инверсный ключ,
законы логики, законы де Моргана.

**Каркас:** что такое высказывание → три операции → схема с ключами →
таблица истинности → элементы на схемах → алгоритм построения таблицы →
законы → итоги.

**Ошибки:** путать И и ИЛИ; считать, что «НЕ» — это просто частица «не»;
забывать, что для n переменных нужно 2ⁿ строк; писать `A = 1` вместо
`A = 0` для инверсного ключа; использовать символы ∧/∨ без проверки шрифта
(в PPTX/PDF надёжнее слова «И», «ИЛИ», «НЕ»).

## Программирование (Python)

**Понятия:** переменная, тип, условие, цикл, функция, аргумент, возврат,
список, словарь, исключение, модуль.

**Каркас:** задача → минимальный код → разбор строк → типичная ошибка → практика.

**Ошибки:** код с отступами в один пробел; `=` вместо `==`; пример, который
не запускается; объяснение синтаксиса вместо идеи.

## Системы счисления и кодирование

**Понятия:** позиционная система, основание, двоичная/восьмеричная/
шестнадцатеричная, бит, байт, ASCII, Unicode, UTF-8.

**Каркас:** зачем нужны разные системы → перевод → пример числа → кодировки →
ошибка «кракозябр» → вывод.

**Ошибки:** 1 Кбайт = 1000 байт без оговорки; путать код символа и его
изображение; утверждать, что Unicode — это кодировка (это набор символов).

## Устройство компьютера

**Понятия:** процессор, ядро, тактовая частота, ОЗУ, ПЗУ, кэш, шина,
накопитель, периферия, архитектура фон Неймана.

**Каркас:** схема «ввод — обработка — хранение — вывод» → процессор → память →
обмен данными → вывод.

**Ошибки:** «ОЗУ хранит файлы»; путать память и накопитель; «чем больше герц,
тем всегда быстрее» без учёта ядер и архитектуры.

## Операционные системы

**Понятия:** ядро, процесс, поток, драйвер, файловая система, права доступа,
планировщик, виртуальная память.

**Каркас:** зачем нужна ОС → ядро и драйверы → файлы и права → процессы →
пример из жизни → вывод.

**Ошибки:** «Windows — это язык программирования»; путать процесс и программу;
считать, что файл всегда лежит на диске непрерывно.

## Компьютерные сети

**Понятия:** клиент-сервер, IP, MAC, порт, протокол, DNS, HTTP/HTTPS, пакет,
маршрутизатор, локальная и глобальная сеть.

**Каркас:** зачем соединять компьютеры → адресация → пакеты и маршрут →
протоколы → HTTPS и безопасность → вывод.

**Ошибки:** «IP-адрес — это номер компьютера в мире» без пояснений; путать
домен и IP; говорить, что HTTPS «шифрует сайт».

## Базы данных

**Понятия:** таблица, запись, поле, тип данных, первичный ключ, связь,
нормализация, SQL, транзакция, индекс.

**Каркас:** проблема хранения → таблица → ключи и связи → запрос → индекс →
вывод.

**Ошибки:** «SQL — это база данных»; путать строку и столбец; пример запроса
с несуществующим полем.

## Информационная безопасность

**Понятия:** конфиденциальность, целостность, доступность, аутентификация,
авторизация, шифрование, фишинг, вредоносное ПО, резервная копия.

**Каркас:** угроза → как атакуют → защита → что делать пользователю → вывод.

**Ошибки:** «антивирус защищает от всего»; путать шифрование и хеширование;
советовать «сложный пароль» без двухфакторной аутентификации.

## Искусственный интеллект

**Понятия:** данные, признаки, обучение с учителем и без, модель, ошибка,
переобучение, нейросеть, генеративные модели, этика и ограничения.

**Каркас:** задача → данные → обучение → проверка → ограничения → пример → вывод.

**Ошибки:** «ИИ всё понимает»; «нейросеть не ошибается»; путать обучение
и программирование правил; обещать универсальную замену специалистов.

## Компьютерная графика

**Понятия:** растр, пиксель, разрешение, вектор, цветовые модели RGB/CMYK,
форматы, сжатие с потерями и без.

**Каркас:** два способа представить изображение → пиксель и вектор → цвет →
формат → выбор под задачу → вывод.

**Ошибки:** «больше пикселей всегда лучше»; путать разрешение экрана и печати;
считать JPEG универсальным для схем и текста.

## Моделирование

**Понятия:** модель, адекватность, допущения, этапы моделирования,
компьютерный эксперимент, верификация.

**Каркас:** объект → зачем модель → допущения → построение → эксперимент →
проверка → вывод.

**Ошибки:** «модель — это копия объекта»; отсутствие допущений; выводы
за пределами применимости модели.

## Университетские темы

Для вуза добавляй: формальные определения, теоремы/свойства, ссылки на
источники (CLRS, Tanenbaum, документация), сравнение подходов, ограничения.
Не превращай слайд в страницу учебника: определение — на слайде, доказательство —
в заметках.
