# Иллюстрации к примерам и алгоритмам

## Когда использовать

- На слайде разбирается пример: перевод числа, деление, вычисление, сортировка.
- Нужно показать **ход решения**, а не только ответ.
- Ученику нужно увидеть, откуда берутся цифры результата.

Правило: нетривиальный пример получает иллюстрацию хода решения. Таблица
с ответами — это сводка, а не замена разбору.

## Инструменты

| Что показать | Чем рисовать |
| --- | --- |
| Деление в столбик, остатки | `division` |
| Разряды числа, веса, сумма | `radix` |
| Процесс из шагов | `flow` или макет `steps` |
| Сравнение двух способов | `two-col` + `note` |
| Массив до/после | `array` |

`division` — основной инструмент для перевода из десятичной системы:
он показывает деление, частное, остаток и направление чтения остатков.

## Порядок работы

1. Запиши пример в `deck.yaml` текстом или таблицей.
2. Создай YAML-описание иллюстрации рядом с картинкой:

   ```yaml
   type: division
   size: [1600, 700]
   number: 13
   base: 2
   answer: "1101"
   ```

3. Собери PNG:

   ```bash
   python3 scripts/illustrations.py decks/<папка>/assets/division-13.yaml
   ```

4. Поставь отдельный слайд `image` **перед** таблицей-сводкой:

   ```yaml
   - layout: image
     title: "Деление в столбик: 13 → 1101"
     image: "assets/division-13.png"
     caption: "Остатки читаем снизу вверх: 1, 0, 1, 1 → 1101"
     notes: "[проверено 2026-11-06] 13 ÷ 2 = 6 (ост. 1), ..."
   ```

5. Проверь, что на картинке сходятся все числа, а ответ совпадает с подписью.

## Требования к иллюстрации примера

- Видны исходные числа, делитель, частное и остаток.
- Остатки выделены и собраны в одном месте.
- Направление чтения показано стрелкой: «снизу вверх».
- Ответ вынесен в отдельную плашку и совпадает с подписью слайда.
- Заголовок слайда не дублируется внутри картинки.
- Цифры крупные: минимум 26–28 px при ширине 1600.
- Для 7 класса — столбик и крупные подписи; для старших — можно компактнее.
- Деление — в российской записи «уголком» (см. раздел ниже), не зарубежной.

## Российская запись примеров

Примеры — для российской школы. Зарубежная запись сбивает ученика: он
видит не тот способ, которым решает в тетради.

| Что | Как писать |
| --- | --- |
| Деление уголком | делимое слева, вертикальная черта, делитель справа; частное — под делителем; произведение — под делимым; остаток — под чертой |
| Умножение и сложение в столбик | разряды друг под другом, ответ под чертой снизу |
| Десятичная дробь | запятая: `3,14`, а не `3.14` |
| Разряды числа | пробел: `1 000 000`, `10 101₂` |
| Дроби | горизонтальная черта, смешанное число `1 1/2` |
| Единицы | `2 Гбайт`, `220 В`, `25 %` |
| Имена и реалии | Иван, Мария, Москва, рубли — не John, New York, `$` |
| Контекст | ЕГЭ и ОГЭ, тетрадь в клетку, задачи про поезда и билеты |

Уголок выглядит так (его и рисует сцена `division`):

```text
  13 │ 2
 −12 │ 6
 ────
   1
```

Проверка: ученик 5–7 класса должен узнать запись и повторить её в тетради
без объяснений.

## `division`: поля

```yaml
type: division
number: 13          # число в десятичной системе
base: 2             # основание, в которое переводим
answer: "1101"      # можно не указывать — соберётся из остатков
steps: [...]        # необязательно: свои шаги
title: "..."        # необязательно
caption: "..."      # необязательно
```

Если `steps` не заданы, шаги считаются автоматически:
`13 → 6 (ост. 1) → 3 (ост. 0) → 1 (ост. 1) → 0 (ост. 1)`.
Остатки читаются снизу вверх: `1101`.

## Чего избегать

- Иллюстрация только с ответом: это не разбор.
- Японская/американская запись деления: делитель слева в скобке, частное
  над делимым. Уголок не переворачивать.
- Мелкие цифры и подписи «для галочки».
- Дублирование таблицы и картинки без различия ролей. Таблица — сводка,
  картинка — ход решения.
- Ответ, которого нет в `notes` или в подписи.
- Числа на картинке не совпадают с текстом слайда.

## Проверка

- [ ] Пример решён, остатки совпадают.
- [ ] Запись российская: уголок, запятая, пробелы между разрядами.
- [ ] Ответ на картинке = ответ в подписи = ответ в `notes`.
- [ ] Стрелка показывает направление чтения.
- [ ] Подписи читаются с последнего ряда.
- [ ] Нет лишнего текста, дублирующего заголовок.
