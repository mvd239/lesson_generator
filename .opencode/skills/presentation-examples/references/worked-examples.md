# Шаблоны иллюстраций к примерам

## Деление в столбик

```yaml
type: division
size: [1600, 700]
number: 13
base: 2
answer: "1101"
```

Что получается:

- четыре блока деления: `13 ÷ 2`, `6 ÷ 2`, `3 ÷ 2`, `1 ÷ 2`;
- запись «уголком» по-русски: делимое слева, делитель за чертой, частное
  под делителем, произведение под делимым, остаток под чертой;
- у каждого — делитель, делимое, частное, произведение и остаток;
- остатки собраны в колонку справа;
- стрелка вверх и подпись «читаем снизу вверх»;
- плашка с ответом.

```text
  13 │ 2
 −12 │ 6
 ────
   1
```

Не переворачивайте уголок и не переносите частное над делимое: это
японская/американская запись, в российских учебниках её нет.

Для другого числа:

```yaml
type: division
number: 25
base: 2
answer: "11001"
```

Для восьмеричной системы:

```yaml
type: division
number: 45
base: 8
answer: "55"
```

## Разряды числа

```yaml
type: radix
size: [1600, 560]
digits: ["1", "0", "1", "1"]
weights: ["2³", "2²", "2¹", "2^0"]
values: [8, 4, 2, 1]
highlight: [0, 2, 3]
sum: "1·8 + 0·4 + 1·2 + 1·1 = 11"
```

Показывает, откуда берётся десятичное значение. Ставьте рядом с `division`:
деление показывает получение цифр, `radix` — их вес.

## Процесс

```yaml
type: flow
steps:
  - title: "Делите на 2"
    text: "Записывайте остаток."
  - title: "Повторяйте"
    text: "Пока частное не станет 0."
  - title: "Читайте снизу вверх"
    text: "Это и есть ответ."
```

Для коротких алгоритмов лучше нативный макет `steps`: он редактируется
в PowerPoint без пересборки картинки.

## Как располагать на слайдах

1. Слайд с алгоритмом (`steps`).
2. Слайд с иллюстрацией примера (`image` + `division`).
3. Слайд-сводка (`table`) — те же шаги в таблице.
4. Слайд с проверкой (`radix` или `image`).
5. Практика: вопросы на слайде, ответы — в `notes`.

## Частые ошибки

- Перепутаны местами частное и остаток.
- Японская запись деления: делитель слева в скобке, частное над делимым.
- Остатки читаются сверху вниз — ответ перевёрнут.
- В ответе оставлены ведущие нули.
- На картинке одно число, в подписи другое.
- `division` использован для огромного числа: блоки становятся мелкими.
  Для длинных примеров делите разбор на два слайда.
