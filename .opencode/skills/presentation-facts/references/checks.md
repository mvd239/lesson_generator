# Что сверять: типовые ошибки по темам

Справочник для скилла `presentation-facts`. Не готовый текст слайдов, а список
мест, где чаще всего врут — и как правильно.

Формулы, таблицы истинности и поведение Python в этом файле проверены запуском
кода; даты — по первичным публикациям и стандартам. Если утверждение зависит
от класса, ориентируйся на учебник, по которому идёт обучение, и укажи это
в `notes`.

## Алгоритмы и сложность

| Утверждение | Как правильно | Частая ошибка |
| --- | --- | --- |
| Пузырьковая сортировка | O(n²) сравнений; с флагом обмена на отсортированных данных O(n); устойчивая; in-place | «всегда O(n²)» |
| Сортировка выбором | Всегда O(n²); неустойчивая; in-place | «устойчивая» |
| Сортировка вставками | O(n²) в среднем, O(n) на почти отсортированных; устойчивая | путать с выбором |
| Сортировка слиянием | Θ(n log n) в любом случае; устойчивая; нужен O(n) дополнительной памяти | «без дополнительной памяти» |
| Быстрая сортировка | O(n log n) в среднем, O(n²) в худшем; обычно неустойчивая | «всегда O(n log n)» |
| Пирамидальная сортировка | O(n log n) всегда; неустойчивая; in-place | «медленнее всех» |
| Двоичный поиск | O(log n), только на отсортированном массиве | «O(log n) на любом массиве» |
| Линейный поиск | O(n) | «O(log n), если повезёт» |
| Хеш-таблица | O(1) в среднем, O(n) в худшем | «всегда O(1)» |
| Поразрядная, счётная | O(n + k), не сравнительные | «тоже O(n log n)» |

Что уточнять на слайде: лучший / средний / худший случай и что именно считается
(сравнения, обмены, дополнительная память). «O(n²)» без этого — половина факта.

## Единицы информации

- 1 байт = 8 бит.
- 1 Кбайт = 1024 байта = 2^10; 1 Мбайт = 1 048 576 байт = 2^20;
  1 Гбайт = 1 073 741 824 байта = 2^30.
- Традиция 1024 — школьная и двоичная. По СИ `кБ` = 1000 байт, двоичная
  приставка — `КиБ`. Обе записи допустимы, но смешивать их в одной формуле нельзя.
- `2^32 = 4 294 967 296`; `2^16 = 65 536`; `2^8 = 256`.
- Скорость канала — в битах: `10 Мбит/с`. Файл 10 МБ (80 Мбит) при такой
  скорости идёт 8 с, а не 1 с. Это самая частая арифметическая ошибка в теме.
- 24 бита на пиксель RGB = 16 777 216 цветов; 8 бит на канал.
- Квантование звука: `частота дискретизации × разрядность × каналы × время`.

## Системы счисления и кодирование

- Шестнадцатеричные цифры: `0–9`, `A–F`. `10₁₆ = 16₁₀`, а не 10.
- `n` бит без знака дают `2^n` значений в диапазоне `0 … 2^n − 1`.
- Байт со знаком в дополнительном коде: `−128 … 127`, а не `−127 … 127`.
- `0.1` в двоичной системе — бесконечная дробь, поэтому `0.1 + 0.2 ≠ 0.3`
  в IEEE 754. Это не «баг Python».
- Перевод в другую систему: деление на основание, остатки читаются снизу вверх.
- ASCII — 7 бит, 128 символов; расширенный ASCII — 8 бит, 256.
- Unicode — не кодировка, а набор символов и кодовых позиций (до `0x10FFFF`).
  UTF-8 — способ записи, 1–4 байта на символ; UTF-16 — 2 или 4 байта.
- Кодировка, шрифт и язык — три разные вещи. «Кракозябры» — несовпадение
  кодировок, а не отсутствие шрифта.
- Кодирование и шифрование — не одно и то же: код не скрывает смысл,
  шифр скрывает и требует ключа.

## Алгебра логики

Проверено перебором всех значений переменных:

| Формула | Тождество |
| --- | --- |
| Законы де Моргана | `¬(A ∧ B) ≡ ¬A ∨ ¬B`, `¬(A ∨ B) ≡ ¬A ∧ ¬B` |
| Импликация | `A → B ≡ ¬A ∨ B` |
| Эквивалентность | `A ↔ B ≡ (A ∧ B) ∨ (¬A ∧ ¬B)` |
| Исключающее ИЛИ | `A ⊕ B ≡ (A ∨ B) ∧ ¬(A ∧ B)` |

- `A → B` и `B → A` — разные высказывания. Обратное не следует из прямого.
- Приоритет операций: `¬`, затем `∧`, затем `∨`, затем `→`, затем `↔`.
  На слайде лучше ставить скобки, даже если они формально не нужны.
- Таблица истинности для `n` переменных — `2^n` строк, порядок `00, 01, 10, 11`.
- «Инверсия» — это НЕ, а не «обратное утверждение». Не путать с отрицанием
  высказывания целиком: `¬(A ∧ B)` — не то же, что `¬A ∧ ¬B`.

## Python: поведение, на которое ссылаются

| Код | Результат | Что подчеркнуть |
| --- | --- | --- |
| `0.1 + 0.2` | `0.30000000000000004` | `== 0.3` даёт `False` |
| `-7 // 2` | `-4` | округление вниз, не к нулю |
| `-7 % 2` | `1` | остаток неотрицательный |
| `int(-7 / 2)` | `-3` | вот это — усечение к нулю |
| `range(5)` | `0,1,2,3,4` | правая граница не входит |
| `sorted([3,1,2])` | новый список | исходный не меняется |
| `[("a",2),("b",1),("c",2)]` по ключу | `b`, затем `a`, `c` | `sorted` устойчива |
| `2**128` | точное целое | `int` не переполняется |

- Индексация с нуля, `s[-1]` — последний символ.
- `input()` всегда возвращает строку: `input() + 1` — ошибка.
- Списки изменяемы, кортежи нет; ключи словаря должны быть хешируемыми.
- `==` сравнивает значения, `is` — идентичность объектов. Для чисел `is`
  работает непредсказуемо — не используй его в примерах.
- Длина строки в Python 3 — число символов, а не байтов.

## Устройство компьютера

- Процессор: АЛУ + устройство управления + регистры. «Мозг компьютера» —
  метафора для объяснения, не определение.
- ОЗУ энергозависима, ПЗУ и флеш-память — нет. «Память» без уточнения
  (оперативная / долговременная) — ошибка.
- 1 ГГц = 10^9 тактов в секунду. Тактовая частота сама по себе не равна
  производительности: важны архитектура, кэш, число ядер.
- Кэш L1/L2/L3 быстрее оперативной памяти, но меньше по объёму; это иерархия,
  а не «ещё одна память».
- У SSD нет движущихся частей; у HDD есть. «SSD быстрее» — верно, но не
  «SSD не изнашивается».
- Машинное слово (32 или 64 бита) — про архитектуру, а не про размер файла.

## Сети

- Интернет ≠ Всемирная паутина. WWW — служба поверх интернета: HTTP + HTML + URL.
- IPv4 — 32 бита, IPv6 — 128 бит. «Адрес в интернете» без версии протокола — неполно.
- DNS переводит имя в IP-адрес; это не «поиск сайта».
- TCP — с установлением соединения и доставкой, UDP — без гарантий.
  «TCP быстрее» — неверно: он надёжнее, но с накладными расходами.
- Порты: 80 — HTTP, 443 — HTTPS. Это значения по умолчанию, их можно менять.
- Wi-Fi — семейство IEEE 802.11, беспроводная локальная сеть. Не «интернет»
  и не «мобильная связь».
- MAC-адрес — 48 бит, выдаётся сетевому интерфейсу; IP-адрес — логический.
- Пропускная способность (бит/с) и время передачи файла — разные величины.

## Определения-ловушки

| Так пишут | В чём ошибка |
| --- | --- |
| «Алгоритм — это программа» | программа — запись алгоритма на языке программирования |
| «Бит — это 0 или 1» | бит — количество информации; 0 и 1 — способ записи |
| «Информация — это данные» | данные — форма представления, информация — снятая неопределённость |
| «Кодирование = шифрование» | код обратим без ключа, шифр — только с ключом |
| «Интернет — это сайты» | сайты — служба WWW поверх интернета |
| «Растровая графика хуже векторной» | у них разное назначение, а не разное качество |
| «ОЗУ и ПЗУ — одно и то же» | разная энергозависимость и назначение |
| «Модель — это уменьшенная копия» | модель — объект-заместитель, сохраняющий нужные свойства |
| «Исполнитель — это компьютер» | исполнитель — любой объект, выполняющий команды |
| «Файл — это документ» | файл — поименованная область на носителе |

## Как быстро проверить

```bash
python3 - <<'PY'
from itertools import product
imp = lambda a, b: (not a) or b
print(all(imp(a, b) == ((not a) or b) for a, b in product([0, 1], repeat=2)))
print(0.1 + 0.2, 0.1 + 0.2 == 0.3)
print(-7 // 2, -7 % 2, 2**32)
PY
```

Вывод должен совпасть с таблицами выше. Не совпал — проверяй, что именно
написано на слайде, и правь слайд, а не справочник.
