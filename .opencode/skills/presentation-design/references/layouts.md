# Макеты слайдов

Все макеты задаются полем `layout` в `deck.yaml`. Ниже — когда какой брать.

| `layout` | Когда использовать | Сколько содержимого |
| --- | --- | --- |
| `title` | Первый слайд: тема + уточнение, класс и год. Данные из `meta`. | — |
| `section` | Начало крупного раздела | номер, заголовок, 1 лид |
| `bullets` | Тезисы, определение, список | 3–7 пунктов (до 12 в 2 колонки) |
| `two-col` | Сравнение двух подходов | 2 колонки по 3–5 пунктов |
| `cards` | 2–4 равноправные идеи | 3 карточки (реже 2 или 4) |
| `steps` | Процесс, алгоритм, порядок действий | 3–5 шагов |
| `table` | Числа, сравнение характеристик | до 7 строк, до 5 столбцов |
| `code` | Пример программы | до 18 строк |
| `image` | Схема, скриншот, фотография | 1 изображение + подпись |
| `team` | Финальный слайд команды | до 6 имён + до 3 QR |
| `summary` | Финальный опорный конспект | 2–4 колонки по 1–5 пунктов |

## Примеры

### title

```yaml
- layout: title
```

Заголовок, подзаголовок, класс и год берутся из `meta`. `subtitle` — это уточнение, что именно разбирается в презентации. Поле `author` не заполняется: презентацию показывает учитель.

### section

```yaml
- layout: section
  number: "02"
  kicker: "Раздел"
  title: "Как устроены базы данных"
  lead: "От таблицы до транзакции — за пять слайдов."
```

### bullets

```yaml
- layout: bullets
  title: "Что такое сортировка"
  kicker: "Определение"          # необязательно
  lead: "Одно предложение."       # необязательно
  bullets:
    - "Обычный пункт"
    - text: "Вложенный пункт"
      level: 1
    - text: "Пункт с акцентом на термине"
      strong: "термин"
  columns: 2                       # необязательно, для 8–12 пунктов
  note: "Вывод в плашке внизу"    # необязательно
  notes: "Что сказать вслух"       # заметки докладчика
```

### two-col

```yaml
- layout: two-col
  title: "Простота против скорости"
  left:
    heading: "Пузырьковая"
    bullets:
      - "Понятный код"
      - "O(n²)"
  right:
    heading: "Быстрая"
    bullets:
      - "O(n log n)"
      - "Сложнее в реализации"
```

В колонке можно вместо `bullets` дать `text`.

### cards

```yaml
- layout: cards
  title: "Где применяется"
  lead: "Необязательный лид."
  cards:
    - number: "1"        # необязательно, по умолчанию 1, 2, 3…
      title: "Поиск"
      text: "До 200 знаков."
    - title: "Базы данных"
      text: "До 200 знаков."
    - title: "Отчёты"
      text: "До 200 знаков."
```

### steps

```yaml
- layout: steps
  title: "Как работает алгоритм"
  steps:
    - title: "Сравнить"
      text: "Одно предложение."
    - title: "Обменять"
      text: "Одно предложение."
```

### table

```yaml
- layout: table
  title: "Сложность алгоритмов"
  columns: ["Алгоритм", "Средняя", "Худшая", "Память"]
  column_widths: [1.6, 1.0, 1.0, 1.0]   # необязательно, относительные
  rows:
    - ["Пузырьковая", "n²", "n²", "1"]
    - ["Быстрая", "n log n", "n²", "log n"]
```

Число ячеек в каждой строке должно совпадать с числом столбцов.

### code

```yaml
- layout: code
  title: "Пузырьковая сортировка"
  language: python
  code: |
    def bubble_sort(a):
        ...
  note: "Пояснение под блоком"   # необязательно
```

Не вставляй табы — используй 4 пробела. Длинные строки сокращай.

### image

```yaml
- layout: image
  title: "Что происходит с массивом"
  image: "assets/sortirovka.png"
  caption: "Подпись под изображением"
```

Путь указывается относительно папки презентации. Поддерживаются PNG и JPG.

### summary

Финальный слайд вместо «Спасибо за внимание». Кратко повторяет всё главное:
понятия, формулы, правила.

```yaml
- layout: summary
  title: "Опорный конспект"
  kicker: "Повторение"
  dark: true
  columns:
    - heading: "Понятия"
      items:
        - "Высказывание истинно или ложно."
        - "Истина = 1, ложь = 0."
    - heading: "Операции"
      items:
        - "НЕ A — инверсия."
        - "A И B истинно только при A = 1 и B = 1."
    - heading: "Формулы"
      items:
        - "НЕ (НЕ A) = A."
        - "A ИЛИ (НЕ A) = 1."
  note: "Инверсный ключ замыкается при A = 0."
```

2–4 колонки, в каждой 1–5 коротких пунктов. Не превращайте конспект в
ещё одну лекцию: только то, что нужно запомнить. `dark: true` сохраняет
тёмный финал — титул и конспект образуют тёмные «обложки».

## Чего избегать

- `end` и «Спасибо за внимание»: финал — опорный конспект.
- Слайд из одной цитаты: цитата — в тезис или `notes`.
- Макет `quote` в новых презентациях не используется.
- Фамилия и имя на титуле: презентацию показывает учитель.
- Отдельный `section` вторым слайдом: уточнение темы уже в подзаголовке.
- Два `section` подряд.
- `cards` из 5+ элементов: текст станет нечитаемым.
- `table` на всю презентацию: максимум 1–2 таблицы.
- `code` без `note`: зритель не поймёт, что важно в примере.
- `image` без подписи и без связи с текстом слайда.
