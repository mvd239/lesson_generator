# Проверка слайда

Прогоняй по каждому слайду перед сдачей. Пункты — не пожелания, а фильтр.

## Смысл

- [ ] На слайде одна мысль, и она понятна без слов автора.
- [ ] Заголовок — утверждение, а не тема.
- [ ] Текст не дублирует то, что и так видно на схеме/таблице.
- [ ] Слайд нужен в рассказе: его можно убрать без потери логики? Тогда уберите.

## Текст

- [ ] Не больше 7 тезисов (12 при двух колонках).
- [ ] Каждый тезис — до 140 знаков.
- [ ] Нет абзацев длиннее 3 строк.
- [ ] Нет канцелярита и «воды».
- [ ] Аббревиатуры расшифрованы при первом упоминании.
- [ ] Нет ошибок и опечаток (прогоните текст через проверку орфографии).
- [ ] Числа, формулы и единицы измерения записаны единообразно.

## Вёрстка

- [ ] Текст не выходит за поля и не наезжает на логотип.
- [ ] Нет обрезанных строк в коде и таблице.
- [ ] Заголовок не занимает больше двух строк.
- [ ] Один акцент на слайде: не три цветных элемента сразу.
- [ ] Отступы между блоками одинаковые.
- [ ] На слайде нет пустой половины без причины.

## Изображения и данные

- [ ] Изображение по теме и читается с последнего ряда.
- [ ] У изображения есть подпись.
- [ ] Нет растянутых/сплющенных картинок (пропорции сохранены).
- [ ] В таблице не больше 7 строк и 5 столбцов.
- [ ] В таблице выделено то, на что смотрит зритель.

## Код

- [ ] Код запускается и делает то, что написано.
- [ ] Строки не длиннее 60 знаков.
- [ ] Отступы пробелами, одинаковые.
- [ ] Есть пояснение: что именно демонстрирует пример.
- [ ] Нет лишних импортов и «магии».

## Титул и финал

- [ ] На титуле нет фамилии и имени.
- [ ] Класс и год указаны.
- [ ] Подзаголовок объясняет, что именно разбирается.
- [ ] Второго слайда-раздела после титула нет.
- [ ] Финал — опорный конспект с ключевыми понятиями и формулами.

## Финальная проверка

- [ ] Титул: тема + уточнение, класс и год, без фамилии и имени.
- [ ] Последний слайд — опорный конспект, а не «Спасибо за внимание».
- [ ] Нумерация слайдов и колонтитул на месте.
- [ ] Логотип виден на тёмных и светлых слайдах.
- [ ] Заметки докладчика заполнены для ключевых слайдов.
- [ ] PPTX открывается в целевом офисе, PDF пролистан целиком.
- [ ] Регламент соблюдён: слайдов не больше, чем успеваете показать.
