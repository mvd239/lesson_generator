# Бриф презентации

## Когда использовать

Всегда **первым**, до `presentation-content`, плана, иллюстраций и сборки.
Задача — не начинать работу на догадках.

## Первый вопрос: режим брифа

Всегда начинай с одного вопроса:

> Хотите задать свои критерии и параметры или взять значения по умолчанию?

Варианты:

- **«Свои параметры»** — задаём P0/P1 и уточняем всё важное.
- **«По умолчанию»** — берём готовый набор и спрашиваем только тему и класс,
  если их нет в сообщении.
- **«Свои + defaults»** — пользователь называет часть параметров, остальное
  берём по умолчанию.

Не начинай содержательную работу, пока не известны **тема** и **класс**.
Остальное в режиме defaults уже задано.

## Значения по умолчанию

| Параметр | Значение |
| --- | --- |
| Формат | **PDF** |
| Цель | объяснение на уроке |
| Объём | **12–15 слайдов** |
| Уровень | **углублённый** |
| Материалы | собираешь сам, без готовых материалов |
| Язык программирования | **Python**, если не задан другой |
| Оформление | текущий modern-стиль проекта |
| Заметки докладчика | да, для ключевых слайдов |
| Практика | 3–4 задания, ответы в `notes` |
| Автор | без ФИО |
| Титул | тема + уточнение, класс и год |
| Финал | тёмный опорный конспект |

Если выбран режим defaults, назови набор вслух и начинай. Не спрашивай
по одному вопросу про формат, объём и уровень.

## Если пользователь выбрал «свои параметры»

### P0 — без этого не стартуем

| Что узнать | Зачем | Если не сказано |
| --- | --- | --- |
| Тема и фокус: что именно раскрыть | Определяет содержание | Спросить |
| Класс/курс | Определяет глубину и ФРП | Спросить |
| Уровень: базовый или углублённый | Определяет сложность | Спросить или advanced |
| Цель: урок, доклад, защита, повторение | Определяет структуру | Спросить |
| Формат: ровно один — PPTX, PDF или HTML | Определяет экспорт | Спросить |
| Объём: минуты или число слайдов | Определяет число слайдов | Предложить 12–15 |

### P1 — сильно влияет, можно уточнить после P0

- По какой программе/учебнику идёт класс; есть ли требования учителя.
- Есть ли готовый конспект, задачи, примеры, ссылки, картинки.
- Нужны ли заметки докладчика и практика с ответами.
- Оформление: логотип, цвета, стиль; или взять текущий modern-стиль.
- Нужна ли раздатка/опорный конспект отдельным файлом.
- Язык программирования, если тема связана с кодом (по умолчанию Python).

### P2 — по умолчанию, не спрашивать без необходимости

- 12–15 слайдов, 10–15 минут.
- Титул и финальный опорный конспект — тёмные; содержательные — светлые.
- Без ФИО автора, с классом и годом.
- Иллюстрации к примерам и алгоритмам — по правилам проекта.
- Язык — русский, термины — по учебнику класса.

## Вопросы для старта в режиме «свои»

Задай одним сообщением, 4–6 пунктов:

1. Тема и что именно нужно раскрыть? (Например: «Системы счисления»,
   фокус — «перевод в двоичную».)
2. Для какого класса/курса и уровня — базовый или углублённый?
3. Цель и формат: урок / доклад / защита? PPTX, PDF или HTML — что-то одно.
4. Сколько слайдов или минут?
5. По какой программе/учебнику? Есть ли конспект, задачи, примеры?
6. Нужны ли заметки, практика с ответами, ваш логотип/цвета? Если тема
   про код — какой язык? По умолчанию Python.

Если удобно, используй `question` для выбора формата, объёма и стиля,
а тему и материалы оставь свободным ответом.

## Если ответили частично

- Уже указанное не переспрашивай — подтверди.
- Если прозвучало «по умолчанию» или «на ваше усмотрение» — применяй defaults
  и спроси только тему и класс, если их нет.
- Для P1/P2 возьми умолчание и назови его: «Беру 12–15 слайдов, PDF,
  углублённый, Python; если нужно иначе — скажите».
- Если не хватает P0 — задай только недостающие вопросы.
- Если пользователь говорит «на ваше усмотрение» — зафиксируй defaults
  и начинай, не возвращаясь с тем же вопросом.

## Итог брифа

Перед работой коротко зафиксируй:

```text
Режим: свои параметры / по умолчанию
Тема: ... · фокус: ...
Класс: ... · уровень: ...
Цель: ... · формат: ...
Объём: ... слайдов
Материалы: ... · язык: ... · оформление: ...
```

Эти данные попадают в `meta` (`title`, `subtitle`, `org`, `grade`, `level`,
`date`, `formats`) и в первый ответ пользователю. Если класс неизвестен —
не выдумывай его.

## Чего не делать

- Не начинать план и текст, пока не ясны тема, класс и режим брифа.
- Не задавать больше 6 вопросов за раз.
- Не спрашивать про формат, объём и уровень, если выбран режим defaults.
- Не спрашивать ФИО автора: презентацию показывает учитель.
- Не спрашивать то, что уже есть в сообщении или во вложении.
- Не предлагать три формата «на всякий случай»: формат — один. Если просят
  несколько, уточни основной; остальные — отдельными запусками.
- Не подменять класс «примерно»: от класса зависит ФРП и глубина.

Полный банк вопросов и готовые формулировки — `references/questions.md`.
