# Вопросы для брифа

## Первый вопрос

Всегда начинай с выбора режима:

> Хотите задать свои критерии и параметры или взять значения по умолчанию?

- **Свои** — переходи к полному набору.
- **По умолчанию** — применяй defaults, спроси только тему и класс,
  если их нет.
- **Смешанный** — уточни названное, остальное возьми по умолчанию.

## Значения по умолчанию

| Параметр | Значение |
| --- | --- |
| Формат | PDF |
| Цель | объяснение на уроке |
| Объём | 12–15 слайдов |
| Уровень | углублённый |
| Материалы | без готовых, собираешь сам |
| Язык программирования | Python |
| Оформление | текущий modern-стиль |
| Заметки | да |
| Практика | 3–4 задания, ответы в `notes` |
| Автор | без ФИО |

## Минимальный набор для режима «свои» (4 вопроса)

1. Тема и что именно раскрыть?
2. Класс/курс и уровень?
3. Цель и формат (PPTX, PDF или HTML)?
4. Сколько слайдов или минут?

Дальше — defaults, назвать вслух.

## Полный набор (6 вопросов)

1. Тема и фокус. Что должно быть понятно после презентации?
2. Класс/курс. Базовый или углублённый уровень?
3. Цель: урок, доклад, защита, повторение?
4. Формат: PPTX, PDF или HTML? Ровно один.
5. Объём: сколько слайдов или минут?
6. Материалы и оформление: есть конспект, задачи, примеры, логотип,
   цвета? Нужны заметки и практика с ответами? Если тема про код —
   какой язык? По умолчанию Python.

## Готовые формулировки

- «Сделайте презентацию по теме “…” для … класса. Что именно раскрыть:
  … . Формат — PDF. Слайдов — 12–15».
- «Тема есть, класс — 8, нужен PPTX для правки. Материалов нет, соберите
  по школьной программе».

## Как выбирать умолчания

| Параметр | Умолчание |
| --- | --- |
| Формат | PDF |
| Объём | 12–15 слайдов |
| Уровень | углублённый |
| Материалы | собираешь сам, без готовых |
| Язык кода | Python |
| Оформление | текущий modern-стиль проекта |
| Заметки | да, для ключевых слайдов |
| Практика | 3–4 задания, ответы в `notes` |
| Автор | не указывать |
| Титул | тема + уточнение, класс, год |
| Финал | опорный конспект |

## Что делать с ответом «по умолчанию»

Не задавай вопросы про формат, объём и уровень. Напиши:

```text
Беру: PDF, объяснение на уроке, 12–15 слайдов, углублённый уровень,
без готовых материалов, Python. Если нужно иначе — скажите.
```

И начинай. Если тема или класс не названы — спроси только их.

## Что делать с ответом «на ваше усмотрение»

Это тот же режим defaults. Не переспрашивай; назови набор и начинай.

## Что не спрашивать

- ФИО и контакты автора.
- Три формата сразу.
- «Нужен ли титул» — нужен всегда.
- «Нужен ли опорный конспект» — нужен всегда.
- «Какой логотип» — он уже в шаблоне; спросить только если пользователь
  хочет заменить.
- Формат, объём и уровень в режиме defaults.

## Пример диалога

```text
Пользователь: Нужна презентация по сортировкам, 10 класс.

Агент: Хотите задать свои параметры или взять значения по умолчанию?
По умолчанию: PDF, объяснение на уроке, 12–15 слайдов, углублённый,
без готовых материалов, Python.

Пользователь: По умолчанию.

Агент: Беру defaults. Тема — сортировки, класс — 10. Начинаю.
```
