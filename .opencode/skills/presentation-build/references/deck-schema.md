# Схема deck.yaml

Файл презентации — YAML с двумя корневыми ключами: `meta` и `slides`.

```yaml
meta:
  title: "Название"
slides:
  - layout: title
```

## meta

| Поле | Обязательно | Значение |
| --- | --- | --- |
| `title` | да | Название на титуле |
| `subtitle` | да | Уточнение: что именно разбирается (1–2 строки) |
| `subject` | нет | Предмет, по умолчанию «Информатика» |
| `audience` | нет | `school`, `college`, `university` |
| `audience_label` | нет | Подпись уровня, если нужна на титуле |
| `author` | нет | **Не заполняйте**: презентацию показывает учитель |
| `org` | да | Класс, например «8 класс» |
| `grade` | нет | Класс числом: `7`–`11`, для сверки с ФРП |
| `level` | нет | `base` или `advanced`; по умолчанию `advanced` |
| `program` | нет | Программа, по которой сверяли, например «ФРП 7–9, 2025» |
| `date` | нет | Год или дата |
| `formats` | нет | Список форматов; по умолчанию `[pdf]` |
| `slug` | нет | Имя папки и файлов; по умолчанию из title |

## slides

Список слайдов. У каждого — `layout` и поля этого макета.

Общие необязательные поля:

- `kicker` — надзаголовок (короткий, 1–3 слова);
- `notes` — заметки докладчика (не выводятся на слайд);
- `title` — заголовок (кроме `title`, где он берётся из `meta`).

### title

```yaml
- layout: title
```

Данные берутся из `meta`: `title` — общая тема, `subtitle` — уточнение,
что именно разбирается; `org` и `date` — класс и год. `author` не заполняется.
Отдельный слайд-раздел вторым после титула не нужен.

### section

```yaml
- layout: section
  number: "01"
  kicker: "Раздел"
  title: "Название раздела"
  lead: "Одно предложение о том, что будет дальше."
```

### bullets

```yaml
- layout: bullets
  title: "Заголовок"
  kicker: "Надзаголовок"
  lead: "Лид, необязательно."
  bullets:
    - "Пункт"
    - text: "Вложенный пункт"
      level: 1
    - text: "Пункт с выделением"
      strong: "выделением"
  columns: 2        # 1 или 2
  note: "Плашка с выводом внизу"
  notes: "Что сказать вслух"
```

- `bullets` — строки или объекты `{text, level, strong}`.
- `level`: 0 — обычный, 1 — вложенный. Глубже не поддерживается.
- `columns: 2` включается автоматически при 8+ пунктах — лучше явно.
- `note` занимает место внизу, уменьшая область тезисов.

### two-col

```yaml
- layout: two-col
  title: "Заголовок"
  left:
    heading: "Слева"
    bullets: ["Пункт", "Пункт"]
  right:
    heading: "Справа"
    text: "Либо текст вместо списка."
```

В каждой колонке: `heading` + (`bullets` или `text`).

### cards

```yaml
- layout: cards
  title: "Заголовок"
  lead: "Необязательно."
  cards:
    - number: "1"
      title: "Заголовок карточки"
      text: "До 200 знаков."
    - title: "Вторая"
      text: "Номер подставится автоматически."
```

Оптимально 3 карточки, максимум 4.

### steps

```yaml
- layout: steps
  title: "Заголовок"
  steps:
    - title: "Шаг"
      text: "Одно предложение."
```

3–5 шагов. Больше — разбейте на два слайда.

### quote (не используется)

Макет оставлен для совместимости со старыми презентациями. В новых
презентациях отдельный слайд-цитата не ставится: цитата идёт в тезис или
в `notes`.

### table

```yaml
- layout: table
  title: "Заголовок"
  columns: ["Столбец 1", "Столбец 2", "Столбец 3"]
  column_widths: [1.6, 1.0, 1.0]   # необязательно
  rows:
    - ["a", "b", "c"]
    - ["d", "e", "f"]
```

- Число ячеек в строке = числу столбцов.
- До 7 строк, до 5 столбцов.
- `column_widths` — относительные веса, не дюймы.

### code

```yaml
- layout: code
  title: "Заголовок"
  language: python
  code: |
    def f(x):
        return x + 1
  note: "Пояснение под блоком"
```

- До 18 строк, до 60 знаков в строке.
- Отступы — пробелами, не табами.
- `language` — короткая подпись в углу (не подсветка синтаксиса).

### image

```yaml
- layout: image
  title: "Заголовок"
  image: "assets/schema.png"
  caption: "Подпись"
```

Путь — относительно папки презентации. PNG или JPG.

Если картинка сгенерирована, рядом с PNG держите её YAML-описание
(`assets/schema.yaml`): по нему картинку можно пересобрать после смены стиля.

### summary

Финальный слайд — краткий опорный конспект всего. Заменяет «Спасибо за
внимание»; `end` в новых презентациях не используется.

```yaml
- layout: summary
  title: "Опорный конспект"
  kicker: "Повторение"
  dark: true
  columns:
    - heading: "Понятия"
      items:
        - "Высказывание истинно или ложно."
        - "Истина = 1, ложь = 0."
    - heading: "Операции"
      items:
        - "НЕ A — инверсия."
        - "A И B истинно только при A = 1 и B = 1."
    - heading: "Формулы"
      items:
        - "НЕ (НЕ A) = A."
        - "A ИЛИ (НЕ A) = 1."
  note: "Инверсный ключ замыкается при A = 0."
```

- 2–4 колонки, в каждой 1–5 коротких пунктов.
- `heading` обязателен.
- `dark: true` — тёмный финал, чтобы сохранить тёмные титул и конспект.
- Это последний слайд презентации.

## Проверки при сборке

Скрипт предупреждает (`!`), если:

- в `meta` указан `author` (ФИО убираем);
- последний слайд — `end` («Спасибо за внимание»);
- второй слайд — `section` (титул и уточнение объединяются);
- тезисов больше 7 (или 12 в две колонки);
- карточек меньше 2 или больше 4;
- шагов больше 5;
- строк таблицы больше 7;
- в строке таблицы не то число ячеек;
- не указан `title` там, где он нужен;
- не найден файл изображения.

Предупреждения не блокируют сборку, но слайд лучше исправить.
