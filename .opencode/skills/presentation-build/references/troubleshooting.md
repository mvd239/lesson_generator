# Частые проблемы

## `ModuleNotFoundError: No module named 'pptx'`

```bash
python3 -m pip install -r requirements.txt
```

Если используется виртуальное окружение, установите зависимости в него.

## `Ошибка шаблона: Не найден шаблон оформления`

Проверьте, что существует `templates/default/theme.yaml`. Если папка шаблона
другая, укажите её:

```bash
python3 scripts/build.py decks/<папка> --theme-dir path/to/theme
```

## `Не найден шрифт с поддержкой кириллицы для PDF`

PDF собирается через ReportLab и требует TTF с кириллицей. Подойдёт один из:

- Arial (`/System/Library/Fonts/Supplemental/Arial.ttf` на macOS,
  `C:/Windows/Fonts/arial.ttf` на Windows);
- Liberation Sans (`/usr/share/fonts/truetype/liberation/`);
- DejaVu Sans (`/usr/share/fonts/truetype/dejavu/`).

На Linux:

```bash
sudo apt install fonts-liberation
```

Можно положить свои файлы в `templates/default/assets/fonts/`:
`body.ttf`, `bold.ttf`, `mono.ttf`, `mono_bold.ttf`.

## Предупреждение `! Слайд №… больше рекомендуемых`

Это не ошибка, но слайд перегружен. Сократите текст или разделите слайд.
Для тезисов можно включить две колонки (`columns: 2`), но не более 12 пунктов.

## Изображение не найдено

Путь в `image:` считается от папки презентации:

```text
decks/02-tema/
├── deck.yaml
└── assets/
    └── schema.png
```

Тогда `image: "assets/schema.png"`. Абсолютные пути работают, но переноситься
на другой компьютер не будут.

## Логотип не виден

- На светлых слайдах используется `templates/default/assets/logo.png` —
  тёмная версия логотипа.
- На тёмных (титул, разделы, финал) — `logo_dark.png` — светлая версия.
- Если вторая версия не найдена, подставляется первая. Проверьте, что обе
  картинки лежат на месте и имеют прозрачный фон.

## После правки theme.yaml ничего не изменилось

Пересоберите шаблон и презентацию:

```bash
python3 scripts/build.py --refresh-template
python3 scripts/build.py decks/<папка>
```

`templates/default/base.pptx` кэширует цвета и шрифты темы.

## Текст обрезается в PPTX

1. Сократите текст — это правильное решение.
2. Проверьте, что не задан лишний `lead` или `note`.
3. Для кода уменьшите число строк (до 18) и длину строк (до 60).
4. Пересоберите: размеры шрифтов подбираются автоматически.

Не уменьшайте шрифт вручную в PowerPoint: при следующей сборке правка пропадёт.

## В Р7-Офисе / МойОфисе съехали шрифты

Причина — подмена Arial на другой шрифт. Варианты:

- отдать PDF (рекомендуется для сдачи);
- оставить в PPTX только Arial и Courier New;
- проверить, что в системе установлены метрически совместимые шрифты.

## PPTX не открывается в LibreOffice

Файл собран только из базовых объектов, поэтому причина обычно во внешнем
содержимом: SVG, SmartArt, 3D, анимации. Проверьте, что в презентации нет
вставленных вручную объектов. Пересборка из `deck.yaml` возвращает чистый файл.

## Сборка падает с `KeyError` или другой ошибкой Python

Проверьте `deck.yaml`:

```bash
python3 scripts/build.py decks/<папка> --check
```

Частые причины: опечатка в `layout`, строка вместо списка в `bullets`,
несовпадение числа ячеек в таблице, табы в блоке `code`.

## Не пересобралась иллюстрация

PNG не обновляется сам. Запустите генератор для её YAML-описания:

```bash
python3 scripts/illustrations.py decks/<папка>/assets/schema.yaml
```

Если меняли палитру — пересоберите все сцены и презентацию.

## Логотип с белым фоном

Используйте `scripts/prepare_logo.py`: он обрежет поля, сделает прозрачный
фон и соберёт белую версию для тёмных слайдов.

```bash
python3 scripts/prepare_logo.py path/to/logo.png
```
