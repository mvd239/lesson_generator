# Сборка презентации

## Когда использовать

- Нужно получить PPTX/PDF/HTML из готового `deck.yaml`.
- Нужно добавить новую презентацию или изображение.
- Сборка падает или файл плохо открывается в другом офисе.

## Команды

```bash
# зависимости (один раз)
python3 -m pip install -r requirements.txt

# проверить deck.yaml без сборки
python3 scripts/build.py decks/<папка> --check

# собрать форматы из meta.formats (по умолчанию — pdf, для диагностики)
python3 scripts/build.py decks/<папка>

# выдать один файл (ровно один формат, см. presentation-export)
python3 scripts/build.py decks/<папка> --formats pdf

# пересобрать шаблон после правки theme.yaml
python3 scripts/build.py --refresh-template
```

Результат: `dist/<slug>/<slug>.pptx`, `.pdf`, `.html`.

Если нужен один конкретный файл — формат выбирается явно и ровно один:
`python3 scripts/build.py decks/<папка> --formats pdf`. Правила выбора
и приёмки файла — в скилле `presentation-export`.

## Новая презентация

```bash
cp -R decks/01-algebra-logiki-8-klass decks/03-moya-tema
```

Заполни `meta` и `slides`. Полное описание полей — `references/deck-schema.md`.

## Форматы

| Формат | Как собирается | Для чего |
| --- | --- | --- |
| `pptx` | python-pptx, базовый `templates/default/base.pptx` | правка в PowerPoint, Р7, МойОфис, LibreOffice |
| `pdf` | ReportLab, те же размеры и цвета | сдача, печать, гарантированное отображение |
| `html` | один автономный файл | показ в браузере, быстрый просмотр |

HTML можно распечатать в PDF средствами браузера (Ctrl/Cmd+P): стили печати
уже настроены под 16:9.

## Совместимость с офисами

PPTX собирается только из базовых объектов: фигуры, текст, таблицы, PNG/JPG.
Это осознанно — так файл одинаково открывается в:

- Microsoft PowerPoint;
- Р7-Офис;
- МойОфис;
- LibreOffice Impress;
- Google Slides (с оговорками по шрифтам).

Правила, которые нельзя нарушать:

- не вставлять SVG в PPTX (используйте PNG);
- не использовать SmartArt, 3D, анимации и переходы;
- шрифты — `Arial` и `Courier New` (метрически совместимы с Liberation Sans/Mono);
- не полагаться на тени и градиенты: только сплошные заливки;
- логотип — PNG с прозрачностью, две версии (для светлого и тёмного фона).

Если в конкретном офисе подменились шрифты, надёжный вариант — отдать PDF.

## Изображения

- Путь в `image:` — относительно папки презентации: `assets/schema.png`.
- Поддерживаются PNG и JPG. SVG не встраивается в PPTX.
- Рекомендуемая ширина — от 1600 px, соотношение 16:9 или 4:3.
- Всегда заполняйте `caption`: подпись объясняет, что на рисунке.

## Шаблон

`templates/default/theme.yaml` — единственный источник цветов, шрифтов и логотипа.
`base.pptx` — производный файл, его не редактируют руками.

После изменения `theme.yaml`:

```bash
python3 scripts/build.py --refresh-template
python3 scripts/build.py decks/<папка>
```

Логотип: `templates/default/assets/logo.png` (для светлых слайдов) и
`logo_dark.png` (белая версия для тёмных). Замените файлы, сохранив имена.

## Иллюстрации и логотип

Иллюстрации собираются из YAML-описаний:

```bash
python3 scripts/illustrations.py decks/<папка>/assets/*.yaml
```

Описание сцены и стиль — в `presentation-illustrations`. PNG кладётся рядом
со спецификацией, в `deck.yaml` указывается относительный путь.

Логотип подготавливается один раз:

```bash
python3 scripts/prepare_logo.py ~/Downloads/logo.png
```

Скрипт обрезает поля, делает прозрачный фон, собирает `logo.png` и белую
`logo_dark.png` для тёмных слайдов, а также печатает основной цвет логотипа.

## Проверка результата

1. Сборка завершилась без `✗` и без предупреждений `!`.
2. Откройте PDF и пролистайте все слайды: нет обрезанного текста,
   наложений и пустых половин.
3. Откройте PPTX в целевом офисе (минимум — в одном из Р7/МойОфис/LibreOffice).
4. Проверьте, что логотип виден на тёмных и светлых слайдах.
5. Проверьте заметки докладчика (в PPTX — панель «Заметки»).
