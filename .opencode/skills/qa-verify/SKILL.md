# Проверка перед сдачей

Загружай этот скилл после сборки `index.html`. Не отдавай игру, пока проверки
не пройдены или пока не объяснено, почему пункт неприменим.

## 1. Автоматическая проверка

Запусти из корня проекта один из вариантов — тот, для которого есть среда.
Скрипты лежат в каталоге этого скилла в глобальном конфиге OpenCode; если в
проекте есть своя копия в `.opencode/skills/qa-verify/scripts/`, используй её.

```bash
# Node.js
node ~/.config/opencode/skills/qa-verify/scripts/check-single-file.mjs "games/<slug>-<класс>/index.html"
```

```powershell
# Windows PowerShell без Node.js
powershell -NoProfile -ExecutionPolicy Bypass -File "$HOME/.config/opencode/skills/qa-verify/scripts/check-single-file.ps1" "games/<slug>-<класс>/index.html"
```

Node.js на школьных Windows-машинах часто не установлен — это нормально,
используй PowerShell-версию. Обе версии выполняют одни и те же проверки.

Скрипт без зависимостей проверяет:

- файл существует и это единственный HTML;
- нет `<script src>`, CDN, `@import` и импортов по URL;
- есть `meta viewport`, `lang="ru"`, Comic Neue с `display=swap`;
- есть обработка Pointer/Touch, `touch-action: none`, `elementFromPoint`;
- есть перезапуск игры и модальное окно;
- нет `draggable="true"` и нативного HTML5 DnD;
- предупреждает о подозрительном размере и отсутствии `prefers-reduced-motion`.

Исправь все `[FAIL]`. Для каждого `[WARN]` реши: исправить или обосновать.

## 2. Чек-лист требований

### Технические

- [ ] Весь код в одном `index.html`, никаких внешних библиотек.
- [ ] Открывается двойным щелчком (`file://`), без сервера и сборки.
- [ ] Единственный внешний запрос — Google Fonts; без сети игра работает.
- [ ] В консоли нет ошибок и предупреждений.
- [ ] HTML валиден: закрыты теги, нет дублей `id`.
- [ ] Нет `console.log` с отладкой и закомментированных кусков кода.

### Механика

- [ ] 6 терминов и 6 заданий; порядок не совпадает.
- [ ] Верный дроп: карточка в зоне, зелёная подсветка, `✓`, +1 балл, карточка
      заблокирована.
- [ ] Неверный дроп: красная подсветка, тряска, `✕`, возврат карточки, ошибка +1.
- [ ] Дроп мимо зоны: возврат без штрафа.
- [ ] Заполненная зона не принимает карточки.
- [ ] Счёт «Верно: N/6» и «Ошибки: N» обновляются сразу.
- [ ] После 6-го верного ответа открывается модальное окно.
- [ ] В окне: «6 из 6», число ошибок, точность, кнопка «Играть снова».
- [ ] Кнопка действительно перезапускает игру.

### Сенсор и адаптив

- [ ] Перетаскивание пальцем работает, страница не прокручивается во время drag.
- [ ] Карточка не «прыгает» под палец.
- [ ] Тап по карточке + тап по зоне работают.
- [ ] Мультитач не создаёт вторую карточку.
- [ ] На 320, 375, 768, 1024 и 1440 px нет горизонтальной прокрутки.
- [ ] До 880 px колонки вертикальные: сначала термины, затем задания.
- [ ] Карточка и зона одинакового размера на каждой ширине.
- [ ] Текст не обрезается, длинный термин переносится.
- [ ] Цели касания не меньше 44×44 px.

### Дизайн и доступность

- [ ] Comic Neue, крупный контрастный текст (не меньше 18 px).
- [ ] Нейтральный фон + плавная тематическая анимация, не мешает чтению.
- [ ] Анимация отключается при `prefers-reduced-motion`.
- [ ] Верно/неверно различается не только цветом (`✓` / `✕`).
- [ ] Видимый `:focus-visible` у карточек, зон и кнопки.
- [ ] `aria-live` сообщает результат, модальное окно имеет `role="dialog"`.
- [ ] Все тексты на русском, без опечаток.

## 3. Ручные сценарии

Проверь минимум эти проходы (в браузере, DevTools → Toggle device toolbar):

1. **Идеальное прохождение:** все 6 верно → финал «6 из 6», ошибок 0,
   точность 100%, «Играть снова» работает.
2. **С ошибками:** 2 неверных дропа → ошибки 2, точность 75%, финал корректен.
3. **Мимо цели:** перетащить в пустое место → карточка вернулась, счёт не
   изменился.
4. **Тач:** включить эмуляцию телефона, перетащить пальцем, проверить отсутствие
   прокрутки.
5. **Клавиатура:** Tab до карточки, Enter, Tab до зоны, Enter → ответ
   проверяется.
6. **Ресайз:** начать drag и повернуть экран/изменить ширину → ghost исчез,
   карточка на месте.
7. **Перезапуск:** нажать «Играть снова» → чистое поле, счёт 0/6, ошибки 0.

```markdown
Готово: `games/egipet-5-klass/index.html`

| № | Термин | Определение |
| - | ------ | ----------- |
...

Проверено: скрипт check-single-file (0 fail), 6/6 пар, touch + pointer,
адаптив 320–1440, финальное окно и перезапуск.

Открыть: двойной щелчок по файлу.
```

Если что-то не удалось проверить (нет тач-устройства, нет Node), скажи об этом
прямо и перечисли, что проверил вручную.
