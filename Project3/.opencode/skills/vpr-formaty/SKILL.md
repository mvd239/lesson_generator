# Типы заданий ВПР

Справка для классификации заданий из файла ВПР и выбора подходящего интерактивного элемента.

## Каталог типов

| Тип задания | Как выглядит в ВПР | Интерактивный элемент |
| --- | --- | --- |
| Выбор одного ответа | Вопрос + 3–4 варианта, верен один | `input[type=radio]` |
| Выбор нескольких ответов | Вопрос + список, верны несколько | `input[type=checkbox]` |
| Краткий ответ | Вопрос, ответ — слово или число | `input[type=text]` |
| Установление соответствия | Два столбца, нужно сопоставить | `select` для каждой пары (или drag-and-drop) |
| Развёрнутый ответ | Задание с пояснением, свободный текст | `textarea` + самопроверка по образцу |
| Восстановление последовательности | Расположить в правильном порядке | нумерованный список / drag-and-drop |

## Правила подготовки пула заданий

- Извлеки из файла ВСЕ задания — не сокращай и не отбирай вручную: случайный выбор 5 заданий выполняется движком теста при каждом запуске.
- Если заданий меньше 5 — используются все имеющиеся.
- Каждое задание оформляй полностью, чтобы из него можно было собрать корректный интерактивный элемент любого типа.

## Что фиксировать по каждому заданию

1. Номер и тип.
2. Полный текст задания, включая инструкцию («Укажи…», «Выпиши…», «Соотнеси…»).
3. Варианты ответа (если есть).
4. Правильный ответ и краткое пояснение (для развёрнутого ответа — образец).
