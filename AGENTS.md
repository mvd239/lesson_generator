# Инструкции для агента

## Назначение репозитория

Генератор презентаций по информатике: `deck.yaml` → PPTX / PDF / HTML.
Оформление — в `templates/default/theme.yaml`, стиль иллюстраций —
в `templates/default/illustrations.yaml`.

## Команды

```bash
python3 -m pip install -r requirements.txt
python3 scripts/build.py decks/<папка> --check
python3 scripts/build.py decks/<папка> --formats pdf   # один формат за запуск
python3 scripts/build.py --refresh-template

# сверка с ФРП
python3 scripts/check_frp.py decks/<папка>

# иллюстрации
python3 scripts/illustrations.py decks/<папка>/assets/*.yaml
python3 scripts/illustrations.py --types

# логотип
python3 scripts/prepare_logo.py path/to/logo.png
```

## Правила

- Источник правды для контента — `decks/<папка>/deck.yaml`.
- Источник правды для оформления — `templates/default/theme.yaml`.
- Источник правды для картинок — YAML-спецификации рядом с PNG, а не сам PNG.
- `templates/default/base.pptx` и `dist/` — производные, руками не правятся.
- Новые макеты добавляются сразу в три рендерера (`render_pptx.py`,
  `render_pdf.py`, `render_html.py`) и в схему скилла.
- Не менять формат `deck.yaml` без обновления
  `.opencode/skills/presentation-build/references/deck-schema.md`.
- Сборка должна проходить без предупреждений `!`; предупреждение — это
  перегруженный или неполный слайд.
- После правки `theme.yaml` пересобрать `base.pptx`.
- После правки `illustrations.yaml` пересобрать PNG из YAML и презентацию.
- Примеры и иллюстрации — в российской школьной записи: деление «уголком»
  (делимое слева, делитель за чертой справа, частное под делителем),
  десятичная запятая, пробел между разрядами, российские имена и реалии.
  Зарубежная запись (делитель слева в скобке, частное над делимым, точка
  вместо запятой) — ошибка, даже если она компактнее.
- `division` в `scripts/illustrations.py` рисует уголок по-русски. Меняя
  сцену, сохраняйте эту запись; зарубежный вариант не добавлять.
- Бриф начинается с вопроса: свои параметры или defaults. Defaults: PDF,
  объяснение на уроке, 12–15 слайдов, углублённый уровень, без готовых
  материалов, Python.
- Титул: тема + уточнение, класс и год. Без `author` (ФИО): показывает учитель.
- Второй слайд не должен быть `section`: титул и уточнение объединяются.
- Последний слайд — `summary` (опорный конспект), не `end` и не «Спасибо».
- Слайд из одной цитаты не ставим: цитата идёт в тезис или в `notes`.
  Если без неё ничего не теряется — убираем.
- Титул и финальный опорный конспект — тёмные; содержательные слайды светлые.
- Экспорт — ровно один формат за запуск: `--formats pdf`. Не собирать
  все три «на всякий случай», формат называет пользователь.
- Проверяемые утверждения получают статус в `notes` слайда:
  `[проверено ГГГГ-ММ-ДД] источник` или `[спорно]`. На слайд пометки не выносятся.
- Проверять результат визуально: PDF пролистывается целиком, PPTX — хотя бы
  одним офисным пакетом.

## Скиллы

- `presentation-brief` — бриф: что спросить до старта.
- `presentation-content` — план и текст.
- `presentation-design` — макеты и чек-лист.
- `presentation-illustrations` — схемы и картинки.
- `presentation-examples` — пошаговые иллюстрации к примерам и алгоритмам.
- `presentation-facts` — проверка фактов, формул, дат и кода.
- `presentation-standards` — сверка с ФГОС и ФРП для класса.
- `presentation-build` — сборка, схема deck.yaml, совместимость.
- `presentation-export` — экспорт ровно одного формата и приёмка файла.

Рабочий цикл: бриф → контент → дизайн → иллюстрации и примеры → проверка
фактов → сверка с ФРП → сборка одного формата → проверка результата.
